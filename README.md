# RK BMS Solutions Website

A responsive, premium one-page website for RK BMS Solutions.

## Files

- `index.html` — website structure and content
- `style.css` — complete responsive styling and animations
- `script.js` — hero slideshow, mobile navigation, scroll reveals and enquiry form
- `assets/` — supplied RK BMS brochure images

## Deploy on GitHub Pages

1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the website URL.

## Important

The hero and gallery currently use high-quality remote Unsplash images. You can replace those URLs in `index.html` with your own project photographs later.

The enquiry form is intentionally serverless. It opens the visitor's email client and prepares an email to:

`rkbmssolutions@gmail.com`

If you later want enquiries to be stored in a database or sent through a professional backend/email service, add a secure backend or form provider rather than putting private API keys in frontend JavaScript.
