# RK BMS Solutions — Main Website

Professional responsive website for RK BMS Solutions.

## Netlify form
The enquiry form is configured with Netlify Forms (`data-netlify="true"`). After deploying this folder to Netlify, form submissions will appear in the Netlify dashboard under Forms. The form redirects to `thank-you.html` after a successful submission.

## Files
- `index.html` — main site
- `style.css` — responsive design
- `script.js` — slideshow, service accordions, FAQ and navigation
- `thank-you.html` — form success page
- `assets/` — RK BMS logo files
